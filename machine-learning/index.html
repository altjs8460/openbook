분류 모델 완성 코드 - 뇌졸중/DecisionTree 흐름

# 1. 도구 불러오기
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

# 2. 데이터 불러오기
data = pd.read_csv('stroke.csv')

# 3. 확인·전처리
print(data.info())

# 4. 문제(X) / 정답(y) 분리
X = data.drop('stroke', axis=1)
y = data['stroke']
X = pd.get_dummies(X)  # 문자열 특성 원-핫 인코딩

# 5. 훈련/평가 데이터 분리
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=7
)

# 6. 모델 생성 → 7. 학습 → 8. 예측 → 9. 평가
model = DecisionTreeClassifier(max_depth=5)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
print(model.score(X_train, y_train))
print(model.score(X_test, y_test))

회귀 모델 완성 코드 - 주택가격/LinearRegression 흐름

import numpy as np
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

X = data.drop('MEDV', axis=1)  # 문제
y = data['MEDV']               # 연속값 정답 → 회귀

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=0
)

model = LinearRegression()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

mse = mean_squared_error(y_test, y_pred)
rmse = np.sqrt(mse)
cv_mean = cross_val_score(model, X_train, y_train, cv=5).mean()
print('MSE:', mse, 'RMSE:', rmse, 'CV 평균:', cv_mean)

스케일링이 필요한 모델의 정확한 순서

split 먼저 → scaler.fit(X_train) → train/test transform → model.fit(변환된 train) → score(변환된 test)
X_train, X_test, y_train, y_test = train_test_split(X, y)
scaler = MinMaxScaler()
scaler.fit(X_train)                 # 훈련 데이터로만 기준 학습
X_train_s = scaler.transform(X_train)
X_test_s = scaler.transform(X_test) # 같은 기준 적용
svm = LinearSVC()
svm.fit(X_train_s, y_train)
svm.score(X_test_s, y_test)
순서 함정: 모델 생성 전에 데이터를 불러오고 X/y를 준비해야 한다. predict는 반드시 fit 뒤. test 데이터에는 모델도, scaler도 fit하지 않는다.

1. 고객의 소득·나이로 대출 승인 여부(승인/거절)를 예측한다. 학습 종류와 문제 유형은?

정답: 지도학습의 분류이다. 정답인 승인 여부가 주어지고, 예측 결과가 승인·거절이라는 범주이기 때문이다.

2. 아파트 정보로 실제 매매가격을 예측한다. 어떤 유형과 평가 지표?

정답: 정답이 있는 지도학습의 회귀 문제이다. 연속적인 숫자인 가격을 예측하므로 MSE와 RMSE는 작을수록 좋고, R²는 1에 가까울수록 좋다.

3. model.predict(X_test)와 model.fit(X_train, y_train) 중 무엇이 먼저?

정답: model.fit(X_train, y_train)이 먼저이다. 훈련 데이터로 규칙을 학습한 후 model.predict(X_test)로 새로운 값을 예측한다.

4. train_test_split의 올바른 반환 순서를 쓰시오.

정답: X_train, X_test, y_train, y_test 순서이다.

5. 직업 컬럼이 문자열이다. DecisionTree 학습 전에 무엇을 해야 하나?

정답: 머신러닝 입력 데이터는 수치여야 하므로 pd.get_dummies()를 이용한 원-핫 인코딩으로 문자열 특성을 숫자화한다.

6. scaler.fit(X_test)를 실행했다. 잘못된 이유는?

정답: 평가 데이터의 정보로 변환 기준을 학습해 데이터 누수가 발생한다. scaler는 X_train에만 fit하고, X_train과 X_test에는 같은 scaler로 transform만 수행한다.

7. 훈련 정확도 1.0, 평가 정확도 0.70이다. 상태와 해결법은?

정답: 훈련 성능에 비해 평가 성능이 낮으므로 과대적합이다. 트리 깊이 제한, 규제 적용, 데이터 추가, 교차 검증 등으로 모델 복잡도를 조절한다.

8. KNN에서 K를 지나치게 작게 설정하면?

정답: 소수의 가까운 데이터와 노이즈에 민감해 결정경계가 복잡해지므로 과대적합 가능성이 커진다.

9. 빈칸: model.____(X_train, y_train) / model.____(X_test)

정답: model.fit(X_train, y_train) / model.predict(X_test)

10. 빈칸: mean_squared_error(____, ____)

정답: mean_squared_error(y_test, y_pred)이다. 실제값을 먼저, 예측값을 다음에 넣는다.

11. cv=5의 의미를 설명하시오.

정답: 훈련 데이터를 5개 fold로 나눈 뒤 4개로 학습하고 1개로 검증하는 과정을, 검증 fold를 바꾸어 총 5번 수행한다. 결과의 평균으로 일반화 성능을 확인한다.

12. 다음을 순서대로 배열: 평가 / 모델 생성 / 데이터 로드 / 예측 / X-y 분리 / 학습 / train-test 분리

정답: 데이터 로드 → X-y 분리 → train-test 분리 → 모델 생성 → 학습 → 예측 → 평가

서술형 답안 공식: “정답 데이터가 있으므로 지도학습이고, 예측값이 [범주/연속값]이므로 [분류/회귀]이다. 데이터를 X와 y로 나누고 train/test로 분리한 뒤, 모델을 생성하여 train으로 학습하고 test로 평가한다.”

# 정답 코드
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier

data = pd.read_csv('bmi_500.csv')
X = data[['Height', 'Weight']]
y = data['Label']

X_train, X_test, y_train, y_test = train_test_split(

)

# 정답 코드
import pandas as pd
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.tree import DecisionTreeClassifier

data = pd.read_csv('stroke.csv')
X = data.drop('stroke', axis=1)
y = data['stroke']

# 문자열 범주형 특성을 수치형으로 변환
X = pd.get_dummies(X)

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=7
)

dt_model = DecisionTreeClassifier(
    max_depth=5, min_samples_split=5, min_samples_leaf=10
)
dt_model.fit(X_train, y_train)

print('훈련 점수:', dt_model.score(X_train, y_train))
print('평가 점수:', dt_model.score(X_test, y_test))
print('교차검증 평균:', cross_val_score(
    dt_model, X_train, y_train, cv=5
).mean())
답안 설명: 문자열 입력 특성은 원-핫 인코딩으로 숫자화한다. 트리 깊이와 분할 조건을 제한해 과대적합을 줄이고, 5-fold 교차 검증으로 일반화 성능을 확인한다.

응용 4. 주택가격 예측과 MSE·RMSE 계산하기 (LinearRegression)

# 정답 코드
import numpy as np
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

# X: 주택 특성 데이터, y: 주택가격(MEDV)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=0
)

linear_model = LinearRegression()
linear_model.fit(X_train, y_train)
y_pred = linear_model.predict(X_test)

mse = mean_squared_error(y_test, y_pred)
rmse = np.sqrt(mse)
r2 = r2_score(y_test, y_pred)
cv_mean = cross_val_score(
    linear_model, X_train, y_train, cv=5
).mean()

print('MSE:', mse)       # 작을수록 좋음
print('RMSE:', rmse)     # 작을수록 좋음
print('R2:', r2)         # 1에 가까울수록 좋음
print('CV 평균:', cv_mean)
답안 설명: 주택가격은 연속값이므로 회귀 문제이다. MSE와 RMSE는 예측 오차이므로 작을수록 좋고, R²는 1에 가까울수록 좋다.

# 정답 코드
from sklearn.linear_model import Lasso, Ridge

lasso_model = Lasso(alpha=10)   # L1: 일부 가중치를 0으로
ridge_model = Ridge(alpha=100)  # L2: 모든 가중치를 작게

lasso_model.fit(X_train, y_train)
ridge_model.fit(X_train, y_train)

print('Lasso 평가 점수:', lasso_model.score(X_test, y_test))
print('Ridge 평가 점수:', ridge_model.score(X_test, y_test))
답안 설명: Lasso는 중요하지 않은 특성의 가중치를 0으로 만들어 특성을 선택하고, Ridge는 모든 특성의 가중치를 골고루 줄인다. alpha가 지나치게 크면 과소적합될 수 있다.

1. 지도학습 / 비지도학습 / 강화학습

개념

2. 과대적합 / 과소적합 / 일반화

train vs test
상태점수 모양뜻·대응
과대적합train 매우 높음, test 낮음훈련을 외움. 모델 단순화, 규제, 데이터 추가, 트리 깊이 제한
과소적합train/test 모두 낮음학습 부족. 복잡도·유용한 특성 증가, 규제 완화
일반화train/test 모두 높고 차이 작음처음 보는 데이터도 잘 예측. 우리가 지향할 상태
train ≫ test → 과대적합
train ≈ test, 둘 다 낮음 → 과소적합
train ≈ test, 둘 다 높음 → 일반화 양호
dt = DecisionTreeClassifier(max_depth=5,

4. 교차 검증 (Cross Validation)

cv=5
한 문장: 훈련 데이터를 여러 fold로 나누고 검증 fold를 번갈아 바꾸며 여러 번 평가해 일반화 성능을 안정적으로 확인하는 방법.
  1. 훈련 데이터를 5개 fold로 분할
  2. 4개로 학습, 1개로 검증
  3. 검증 fold를 바꿔 총 5번 반복
  4. 5개 점수의 평균 확인
[검증][학습][학습][학습][학습] → 검증 위치를 순환 → 5개 점수 평균
from sklearn.model_selection import cross_val_score
scores = cross_val_score(model, X_train, y_train, cv=5)
print(scores, scores.mean())

cross_val_score = 현재 모델 성능 검증. GridSearchCV = 교차 검증으로 최적 하이퍼파라미터 조합 탐색.

주의: 최종 test는 모델 선택에 반복 사용하지 않는다. 전처리는 train에만 fit하고 test에는 transform만 한다.

6. 회귀 모델

연속값
ŷ = w₁x₁ + w₂x₂ + … + wₚxₚ + b
w = 가중치(coef_), b = 절편(intercept_)
모델핵심특징
LinearRegressionMSE 최소의 w,b 탐색빠르고 해석 쉬움. 자체 복잡도 조절이 없어 특성 확장 시 과대적합 가능
SGDRegressor경사하강법으로 w 반복 갱신대용량. max_iter, eta0(학습률)
Lasso (L1)|w| 합에 벌점, 일부 w=0과대적합 완화 + 자동 특성 선택
Ridge (L2)w² 합에 벌점, 모든 w 축소특성을 유지하며 안정화
alpha가 커지면 규제가 강해져 모델이 단순해지고 과대적합이 줄 수 있으나, 너무 크면 과소적합·오차 증가.
from sklearn.linear_model import LinearRegression, Lasso, Ridge
linear = LinearRegression()
lasso = Lasso(alpha=10)   # L1
ridge = Ridge(alpha=100)  # L2

Lasso = Leave some out (일부 계수 0), Ridge = Reduce all (전체 계수 축소).

7. 회귀 평가: MSE / RMSE

작을수록 좋음
지표뜻·특징방향
MSE오차 제곱의 평균. 큰 오차에 큰 벌점, 단위가 제곱0에 가까울수록 좋음
RMSEMSE의 제곱근. 원래 y와 같은 단위0에 가까울수록 좋음
MAE절대 오차 평균. 이상치 영향이 상대적으로 작음작을수록
R²회귀선의 설명력. 심하게 나쁘면 음수 가능1에 가까울수록
오차 = 예측값 - 실제값
MSE = 평균((예측값 - 실제값)²)
RMSE = √MSE
import numpy as np
from sklearn.metrics import mean_squared_error, r2_score
mse = mean_squared_error(y_test, y_pred)
rmse = np.sqrt(mse)
r2 = r2_score(y_test, y_pred)
분류 .score()는 보통 정확도, 회귀 .score()는 R² → 클수록 좋음. MSE/RMSE는 오차 → 작을수록 좋음.

복붙
import pandas as pd
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.tree import DecisionTreeClassifier

data = pd.read_csv('data.csv')
X = pd.get_dummies(data.drop('target', axis=1))
y = data['target']

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=7
)
model = DecisionTreeClassifier(max_depth=5)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

print('train:', model.score(X_train, y_train))
print('test :', model.score(X_test, y_test))
print('CV   :', cross_val_score(model, X_train, y_train, cv=5).mean())
