1. 지도학습 / 비지도학습 / 강화학습

개념
종류정답핵심예시
지도학습y 있음X와 y의 관계 학습분류, 회귀
비지도학습y 없음내부 구조·패턴·그룹 발견군집, 차원 축소
강화학습정답표 대신 보상행동하며 누적 보상 최대화게임, 로봇
판별: 정답 라벨이 있으면 지도, 비슷한 것끼리 묶으면 비지도, 행동 결과로 보상을 받으면 강화학습.

분류

정답이 종류/범주. BMI 등급, 뇌졸중 여부, 손글씨 0~9.

회귀

정답이 연속 숫자. 성적, 주택가격, 기온.

2. 과대적합 / 과소적합 / 일반화

train vs test
상태점수 모양뜻·대응
과대적합train 매우 높음, test 낮음훈련을 외움. 모델 단순화, 규제, 데이터 추가, 트리 깊이 제한
과소적합train/test 모두 낮음학습 부족. 복잡도·유용한 특성 증가, 규제 완화
일반화train/test 모두 높고 차이 작음처음 보는 데이터도 잘 예측. 우리가 지향할 상태
train ≫ test → 과대적합
train ≈ test, 둘 다 낮음 → 과소적합
train ≈ test, 둘 다 높음 → 일반화 양호
dt = DecisionTreeClassifier(max_depth=5,
                            min_samples_split=5,
                            min_samples_leaf=10)
dt.fit(X_train, y_train)
print(dt.score(X_train, y_train), dt.score(X_test, y_test))

4종 비교

Decision Tree질문을 반복해 분할. 해석 쉽고 스케일 영향 적음깊으면 과대적합. max_depth, min_samples_*

SVM / LinearSVC클래스 사이 마진이 최대인 경계. 고차원에 강함스케일링 중요. C로 규제 조절

4. 교차 검증 (Cross Validation)

cv=5
한 문장: 훈련 데이터를 여러 fold로 나누고 검증 fold를 번갈아 바꾸며 여러 번 평가해 일반화 성능을 안정적으로 확인하는 방법.
  1. 훈련 데이터를 5개 fold로 분할
  2. 4개로 학습, 1개로 검증
  3. 검증 fold를 바꿔 총 5번 반복
  4. 5개 점수의 평균 확인
[검증][학습][학습][학습][학습] → 검증 위치를 순환 → 5개 점수 평균
from sklearn.model_selection import cross_val_score
scores = cross_val_score(model, X_train, y_train, cv=5)
print(scores, scores.mean())

cross_val_score = 현재 모델 성능 검증. GridSearchCV = 교차 검증으로 최적 하이퍼파라미터 조합 탐색.

주의: 최종 test는 모델 선택에 반복 사용하지 않는다. 전처리는 train에만 fit하고 test에는 transform만 한다.

6. 회귀 모델

연속값
ŷ = w₁x₁ + w₂x₂ + … + wₚxₚ + b
w = 가중치(coef_), b = 절편(intercept_)
모델핵심특징
LinearRegressionMSE 최소의 w,b 탐색빠르고 해석 쉬움. 자체 복잡도 조절이 없어 특성 확장 시 과대적합 가능
SGDRegressor경사하강법으로 w 반복 갱신대용량. max_iter, eta0(학습률)
Lasso (L1)|w| 합에 벌점, 일부 w=0과대적합 완화 + 자동 특성 선택
Ridge (L2)w² 합에 벌점, 모든 w 축소특성을 유지하며 안정화
alpha가 커지면 규제가 강해져 모델이 단순해지고 과대적합이 줄 수 있으나, 너무 크면 과소적합·오차 증가.
from sklearn.linear_model import LinearRegression, Lasso, Ridge
linear = LinearRegression()
lasso = Lasso(alpha=10)   # L1
ridge = Ridge(alpha=100)  # L2

Lasso = Leave some out (일부 계수 0), Ridge = Reduce all (전체 계수 축소).

7. 회귀 평가: MSE / RMSE

작을수록 좋음
지표뜻·특징방향
MSE오차 제곱의 평균. 큰 오차에 큰 벌점, 단위가 제곱0에 가까울수록 좋음
RMSEMSE의 제곱근. 원래 y와 같은 단위0에 가까울수록 좋음
MAE절대 오차 평균. 이상치 영향이 상대적으로 작음작을수록
R²회귀선의 설명력. 심하게 나쁘면 음수 가능1에 가까울수록
오차 = 예측값 - 실제값
MSE = 평균((예측값 - 실제값)²)
RMSE = √MSE
import numpy as np
from sklearn.metrics import mean_squared_error, r2_score
mse = mean_squared_error(y_test, y_pred)
rmse = np.sqrt(mse)
r2 = r2_score(y_test, y_pred)
분류 .score()는 보통 정확도, 회귀 .score()는 R² → 클수록 좋음. MSE/RMSE는 오차 → 작을수록 좋음.

8. 머신러닝 7과정

문수전탐모학평
암기: 문-수-전-탐-모-학-평
  1. 문제 정의: 지도/비지도, 분류/회귀, 목표 결정
  2. 데이터 수집: 파일, DB, 크롤링, 공공데이터, 센서, 설문
  3. 전처리: 결측·이상치, 인코딩, 스케일링, 특성공학
  4. EDA: 특성 의미, 통계, 분포·상관, 시각화
  5. 모델 선택·하이퍼파라미터 조정: K, 깊이, alpha, C
  6. 모델 학습·예측: fit → predict
  7. 평가: 정확도, MSE/RMSE/R², 교차 검증

데이터 분리 원칙

X/y · train/test
X입력 특성, 반드시 2차원 (행, 특성 수)
y정답/예측 대상, 보통 1차원 (행,)
train규칙을 학습하는 데이터
test학습에 쓰지 않고 마지막 일반화 성능 평가
from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=7
)

단순 슬라이싱은 정렬 데이터에서 편향될 수 있다. 분리 후 shape로 행 수와 차원을 확인.

스케일링

KNN · SVM

특성 범위가 크게 다르면 큰 숫자의 특성이 거리·경계 계산을 지배한다. 손글씨 SVM 실습은 MinMaxScaler로 0~1 범위를 사용했다.

from sklearn.preprocessing import MinMaxScaler
scaler = MinMaxScaler()
scaler.fit(X_train)
X_train_s = scaler.transform(X_train)
X_test_s = scaler.transform(X_test)
분리 전 전체 데이터에 scaler를 fit하면 test 정보가 섞이는 데이터 누수.

실전 코드 전체 흐름

복붙
import pandas as pd
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.tree import DecisionTreeClassifier

data = pd.read_csv('data.csv')
X = pd.get_dummies(data.drop('target', axis=1))
y = data['target']

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=7
)
model = DecisionTreeClassifier(max_depth=5)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

print('train:', model.score(X_train, y_train))
print('test :', model.score(X_test, y_test))
print('CV   :', cross_val_score(model, X_train, y_train, cv=5).mean())
