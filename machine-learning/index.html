분류 모델 완성 코드 - 뇌졸중/DecisionTree 흐름

# 1. 도구 불러오기
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

# 2. 데이터 불러오기
data = pd.read_csv('stroke.csv')

# 3. 확인·전처리
print(data.info())

# 4. 문제(X) / 정답(y) 분리
X = data.drop('stroke', axis=1)
y = data['stroke']
X = pd.get_dummies(X)  # 문자열 특성 원-핫 인코딩

# 5. 훈련/평가 데이터 분리
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=7
)

# 6. 모델 생성 → 7. 학습 → 8. 예측 → 9. 평가
model = DecisionTreeClassifier(max_depth=5)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
print(model.score(X_train, y_train))
print(model.score(X_test, y_test))

회귀 모델 완성 코드 - 주택가격/LinearRegression 흐름

import numpy as np
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

X = data.drop('MEDV', axis=1)  # 문제
y = data['MEDV']               # 연속값 정답 → 회귀

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=0
)

model = LinearRegression()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

mse = mean_squared_error(y_test, y_pred)
rmse = np.sqrt(mse)
cv_mean = cross_val_score(model, X_train, y_train, cv=5).mean()
print('MSE:', mse, 'RMSE:', rmse, 'CV 평균:', cv_mean)

스케일링이 필요한 모델의 정확한 순서

split 먼저 → scaler.fit(X_train) → train/test transform → model.fit(변환된 train) → score(변환된 test)
X_train, X_test, y_train, y_test = train_test_split(X, y)
scaler = MinMaxScaler()
scaler.fit(X_train)                 # 훈련 데이터로만 기준 학습
X_train_s = scaler.transform(X_train)
X_test_s = scaler.transform(X_test) # 같은 기준 적용
svm = LinearSVC()
svm.fit(X_train_s, y_train)
svm.score(X_test_s, y_test)
순서 함정: 모델 생성 전에 데이터를 불러오고 X/y를 준비해야 한다. predict는 반드시 fit 뒤. test 데이터에는 모델도, scaler도 fit하지 않는다.

🧩 응용문제 12개 + 바로 쓰는 정답

답 전부 펼침
사용법: 문제와 가장 비슷한 유형을 찾은 뒤, 파란색 정답 문장을 그대로 참고해서 작성하세요. 모든 답은 처음부터 펼쳐져 있습니다.
1. 고객의 소득·나이로 대출 승인 여부(승인/거절)를 예측한다. 학습 종류와 문제 유형은?

정답: 지도학습의 분류이다. 정답인 승인 여부가 주어지고, 예측 결과가 승인·거절이라는 범주이기 때문이다.

2. 아파트 정보로 실제 매매가격을 예측한다. 어떤 유형과 평가 지표?

정답: 정답이 있는 지도학습의 회귀 문제이다. 연속적인 숫자인 가격을 예측하므로 MSE와 RMSE는 작을수록 좋고, R²는 1에 가까울수록 좋다.

3. model.predict(X_test)와 model.fit(X_train, y_train) 중 무엇이 먼저?

정답: model.fit(X_train, y_train)이 먼저이다. 훈련 데이터로 규칙을 학습한 후 model.predict(X_test)로 새로운 값을 예측한다.

4. train_test_split의 올바른 반환 순서를 쓰시오.

정답: X_train, X_test, y_train, y_test 순서이다.

5. 직업 컬럼이 문자열이다. DecisionTree 학습 전에 무엇을 해야 하나?

정답: 머신러닝 입력 데이터는 수치여야 하므로 pd.get_dummies()를 이용한 원-핫 인코딩으로 문자열 특성을 숫자화한다.

6. scaler.fit(X_test)를 실행했다. 잘못된 이유는?

정답: 평가 데이터의 정보로 변환 기준을 학습해 데이터 누수가 발생한다. scaler는 X_train에만 fit하고, X_train과 X_test에는 같은 scaler로 transform만 수행한다.

7. 훈련 정확도 1.0, 평가 정확도 0.70이다. 상태와 해결법은?

정답: 훈련 성능에 비해 평가 성능이 낮으므로 과대적합이다. 트리 깊이 제한, 규제 적용, 데이터 추가, 교차 검증 등으로 모델 복잡도를 조절한다.

8. KNN에서 K를 지나치게 작게 설정하면?

정답: 소수의 가까운 데이터와 노이즈에 민감해 결정경계가 복잡해지므로 과대적합 가능성이 커진다.

9. 빈칸: model.____(X_train, y_train) / model.____(X_test)

정답: model.fit(X_train, y_train) / model.predict(X_test)

10. 빈칸: mean_squared_error(____, ____)

정답: mean_squared_error(y_test, y_pred)이다. 실제값을 먼저, 예측값을 다음에 넣는다.

11. cv=5의 의미를 설명하시오.

정답: 훈련 데이터를 5개 fold로 나눈 뒤 4개로 학습하고 1개로 검증하는 과정을, 검증 fold를 바꾸어 총 5번 수행한다. 결과의 평균으로 일반화 성능을 확인한다.

12. 다음을 순서대로 배열: 평가 / 모델 생성 / 데이터 로드 / 예측 / X-y 분리 / 학습 / train-test 분리

정답: 데이터 로드 → X-y 분리 → train-test 분리 → 모델 생성 → 학습 → 예측 → 평가

서술형 답안 공식: “정답 데이터가 있으므로 지도학습이고, 예측값이 [범주/연속값]이므로 [분류/회귀]이다. 데이터를 X와 y로 나누고 train/test로 분리한 뒤, 모델을 생성하여 train으로 학습하고 test로 평가한다.”

응용 1. 키·몸무게로 BMI 등급 예측하기 (KNN)

# 정답 코드
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier

data = pd.read_csv('bmi_500.csv')
X = data[['Height', 'Weight']]
y = data['Label']

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=7
)

knn_model = KNeighborsClassifier(n_neighbors=13)
knn_model.fit(X_train, y_train)

print('훈련 점수:', knn_model.score(X_train, y_train))
print('평가 점수:', knn_model.score(X_test, y_test))
print('새 데이터 예측:', knn_model.predict([[170, 70]]))
답안 설명: BMI 등급은 여러 범주 중 하나를 예측하므로 지도학습의 분류 문제이다. KNN은 가까운 13개 이웃의 정답을 참고해 새로운 사람의 BMI 등급을 예측한다.

응용 2. 문자열 특성이 있는 뇌졸중 여부 예측하기 (DecisionTree)

# 정답 코드
import pandas as pd
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.tree import DecisionTreeClassifier

data = pd.read_csv('stroke.csv')
X = data.drop('stroke', axis=1)
y = data['stroke']

# 문자열 범주형 특성을 수치형으로 변환
X = pd.get_dummies(X)

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=7
)

dt_model = DecisionTreeClassifier(
    max_depth=5, min_samples_split=5, min_samples_leaf=10
)
dt_model.fit(X_train, y_train)

print('훈련 점수:', dt_model.score(X_train, y_train))
print('평가 점수:', dt_model.score(X_test, y_test))
print('교차검증 평균:', cross_val_score(
    dt_model, X_train, y_train, cv=5
).mean())
답안 설명: 문자열 입력 특성은 원-핫 인코딩으로 숫자화한다. 트리 깊이와 분할 조건을 제한해 과대적합을 줄이고, 5-fold 교차 검증으로 일반화 성능을 확인한다.

응용 3. 손글씨 숫자 분류하기 (LinearSVC + 스케일링)

# 정답 코드
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import MinMaxScaler
from sklearn.svm import LinearSVC

digit_data = pd.read_csv('digit_train.csv')
X = digit_data.drop('label', axis=1)
y = digit_data['label']

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=7
)

scaler = MinMaxScaler()
scaler.fit(X_train)                   # train에만 fit
X_train_scaled = scaler.transform(X_train)
X_test_scaled = scaler.transform(X_test)

svm = LinearSVC()
svm.fit(X_train_scaled, y_train)
print('평가 점수:', svm.score(X_test_scaled, y_test))
답안 설명: 픽셀 특성의 범위를 0~1로 맞추면 SVM이 더 안정적으로 학습한다. 데이터 누수를 막기 위해 scaler는 X_train에만 fit한다.

응용 4. 주택가격 예측과 MSE·RMSE 계산하기 (LinearRegression)

# 정답 코드
import numpy as np
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

# X: 주택 특성 데이터, y: 주택가격(MEDV)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=0
)

linear_model = LinearRegression()
linear_model.fit(X_train, y_train)
y_pred = linear_model.predict(X_test)

mse = mean_squared_error(y_test, y_pred)
rmse = np.sqrt(mse)
r2 = r2_score(y_test, y_pred)
cv_mean = cross_val_score(
    linear_model, X_train, y_train, cv=5
).mean()

print('MSE:', mse)       # 작을수록 좋음
print('RMSE:', rmse)     # 작을수록 좋음
print('R2:', r2)         # 1에 가까울수록 좋음
print('CV 평균:', cv_mean)
답안 설명: 주택가격은 연속값이므로 회귀 문제이다. MSE와 RMSE는 예측 오차이므로 작을수록 좋고, R²는 1에 가까울수록 좋다.

응용 5. 과대적합된 선형회귀에 L1·L2 규제 적용하기

# 정답 코드
from sklearn.linear_model import Lasso, Ridge

lasso_model = Lasso(alpha=10)   # L1: 일부 가중치를 0으로
ridge_model = Ridge(alpha=100)  # L2: 모든 가중치를 작게

lasso_model.fit(X_train, y_train)
ridge_model.fit(X_train, y_train)

print('Lasso 평가 점수:', lasso_model.score(X_test, y_test))
print('Ridge 평가 점수:', ridge_model.score(X_test, y_test))
답안 설명: Lasso는 중요하지 않은 특성의 가중치를 0으로 만들어 특성을 선택하고, Ridge는 모든 특성의 가중치를 골고루 줄인다. alpha가 지나치게 크면 과소적합될 수 있다.

응용 6. 최적의 트리 깊이를 교차 검증으로 찾기 (GridSearchCV)

# 정답 코드
from sklearn.model_selection import GridSearchCV
from sklearn.tree import DecisionTreeClassifier

params = {
    'max_depth': [3, 5, 7, 10],
    'min_samples_split': [2, 5, 10],
    'min_samples_leaf': [1, 5, 10]
}

grid = GridSearchCV(
    DecisionTreeClassifier(), params, cv=5
)
grid.fit(X_train, y_train)

print('최적 파라미터:', grid.best_params_)
print('최고 교차검증 점수:', grid.best_score_)

답안 설명: GridSearchCV는 지정한 하이퍼파라미터 조합을 5-fold 교차 검증으로 비교해 가장 성능이 좋은 조합을 찾는다.

1. 선형회귀는 무엇을 찾는 모델인가?

선형회귀는 여러 데이터 사이를 가장 잘 지나가는 직선을 찾고, 그 직선으로 연속적인 숫자를 예측합니다.

예측값 ŷ = w × x + b
w(weight, 가중치) = 직선의 기울기
b(bias, 편향·절편) = 직선이 y축과 만나는 위치
값무슨 역할?성적 예측 예시
x모델에 넣는 입력 특성공부 시간
y실제 정답실제 시험 성적
ŷ모델이 계산한 예측값예상 성적
wx가 1 증가할 때 ŷ가 얼마나 변하는지1시간 공부할 때 10점 증가
bx가 0일 때 시작하는 예측값공부 0시간일 때 기본점수
예: 모델이 ŷ = 10x + 0을 찾았다면 7시간 공부한 학생의 예측 성적은 10×7=70점입니다.

2. “가장 좋은 직선”은 어떻게 판단하나?

직선을 아무렇게나 그릴 수는 없습니다. 각 데이터에서 예측값과 실제값의 차이를 계산하고, 그 차이가 전체적으로 가장 작은 직선을 선택합니다.

오차(error) = 예측값(ŷ) - 실제값(y)
MSE = 모든 오차를 제곱한 뒤 평균
좋은 직선 = MSE가 가장 작은 w와 b를 가진 직선

오차를 그냥 더하면 +오차와 -오차가 서로 상쇄될 수 있어 제곱합니다. 제곱하면 모든 값이 양수가 되고, 큰 실수에는 더 큰 벌점이 주어집니다.

3. 경사하강법(Gradient Descent)을 쉽게 이해하기

경사하강법은 정답 w를 한 번에 계산하지 않고, 현재 w에서 시작해 MSE가 작아지는 방향으로 w를 조금씩 바꾸는 방법입니다.

산에서 내려오는 비유

안개 때문에 산 전체는 안 보이지만, 발밑의 기울기는 알 수 있습니다. 가장 낮은 골짜기로 가려면 아래로 기울어진 방향으로 한 걸음씩 이동합니다.

머신러닝에서는

산의 높이 = MSE
현재 위치 = 현재 w
내려갈 방향 = 기울기의 반대 방향
한 걸음 크기 = 학습률

① w를 임의로 시작
② 현재 w로 예측
③ MSE 계산
④ MSE가 감소하는 방향 확인
⑤ w를 조금 수정
⑥ 충분히 작아질 때까지 반복

기울기가 양수라면 w를 줄이고, 기울기가 음수라면 w를 늘리는 방향으로 이동합니다. 수학적으로는 기울기의 반대 방향으로 움직입니다.

for epoch in range(반복횟수):
    y_pred = w * X + b
    mse = ((y_pred - y) ** 2).mean()

6. 선형회귀가 과대적합되는 이유와 규제

특성을 지나치게 많이 만들면 훈련 데이터의 작은 변화와 노이즈까지 설명하려고 가중치가 매우 커질 수 있습니다. 훈련 점수는 높지만 새로운 데이터에서는 성능이 떨어집니다.

Lasso (L1)

MSE에 |w|의 합을 벌점으로 추가합니다. 중요하지 않은 w가 정확히 0이 될 수 있어 특성 선택 효과가 있습니다.

Ridge (L2)

MSE에 w²의 합을 벌점으로 추가합니다. 모든 w를 골고루 작게 만들어 모델을 부드럽게 합니다.

최종 목표 = 예측 오차(MSE) + 가중치가 너무 클 때의 벌점
alpha ↑ → 규제 강함 → 모델 단순
alpha가 너무 크면 → 과소적합 가능

7. 선형분류는 직선으로 어떻게 종류를 나누나?

선형분류도 먼저 w₁x₁ + w₂x₂ + … + b를 계산합니다. 다만 숫자 자체를 최종 답으로 쓰지 않고, 기준을 중심으로 어느 클래스에 속하는지 결정합니다.

선형식 결과 > 0 → 양성 클래스(+1)
선형식 결과 < 0 → 음성 클래스(-1)
결과가 0이 되는 선 → 두 클래스를 가르는 결정경계

특성이 2개이면 결정경계는 선, 특성이 3개이면 평면, 더 많으면 초평면이라고 부릅니다.

8. LogisticRegression과 sigmoid

선형식은 -∞부터 +∞까지 어떤 값도 나올 수 있습니다. 이를 확률처럼 해석하려고 sigmoid 함수를 사용해 결과를 0~1 사이로 압축합니다.

sigmoid(아주 큰 양수) ≈ 1
sigmoid(0) = 0.5
sigmoid(아주 작은 음수) ≈ 0
sigmoid 결과해석예측
0.87양성일 확률 87%기준 0.5 이상 → 1
0.18양성일 확률 18%기준 0.5 미만 → 0
이름 함정: LogisticRegression이라는 이름이지만 최종 결과가 클래스이므로 분류 모델입니다.

9. SVM은 왜 “마진”을 크게 만들까?

두 클래스를 나누는 선은 여러 개 그을 수 있습니다. SVM은 그중 가장 가까운 데이터들과 결정경계 사이 거리가 가장 큰 선을 선택합니다.

용어뜻
서포트 벡터결정경계에 가장 가까워 경계 위치를 결정하는 핵심 데이터
마진결정경계와 서포트 벡터 사이의 거리
좋은 경계마진이 커서 새로운 데이터가 조금 흔들려도 안정적으로 분류하는 경계
스케일링 연결: SVM과 KNN은 거리의 영향을 많이 받습니다. 한 특성은 0~1, 다른 특성은 0~10000이면 큰 값의 특성이 경계를 지배하므로 MinMaxScaler 등으로 범위를 맞춥니다.

7. 회귀 평가: MSE / RMSE

작을수록 좋음
지표뜻·특징방향
MSE오차 제곱의 평균. 큰 오차에 큰 벌점, 단위가 제곱0에 가까울수록 좋음
RMSEMSE의 제곱근. 원래 y와 같은 단위0에 가까울수록 좋음
MAE절대 오차 평균. 이상치 영향이 상대적으로 작음작을수록
R²회귀선의 설명력. 심하게 나쁘면 음수 가능1에 가까울수록
오차 = 예측값 - 실제값
MSE = 평균((예측값 - 실제값)²)
RMSE = √MSE
import numpy as np
from sklearn.metrics import mean_squared_error, r2_score
mse = mean_squared_error(y_test, y_pred)
rmse = np.sqrt(mse)
r2 = r2_score(y_test, y_pred)
분류 .score()는 보통 정확도, 회귀 .score()는 R² → 클수록 좋음. MSE/RMSE는 오차 → 작을수록 좋음.

  6. 모델 학습·예측: fit → predict
  7. 평가: 정확도, MSE/RMSE/R², 교차 검증

데이터 분리 원칙

X/y · train/test
X입력 특성, 반드시 2차원 (행, 특성 수)
y정답/예측 대상, 보통 1차원 (행,)
train규칙을 학습하는 데이터
test학습에 쓰지 않고 마지막 일반화 성능 평가
from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=7
)

단순 슬라이싱은 정렬 데이터에서 편향될 수 있다. 분리 후 shape로 행 수와 차원을 확인.

스케일링

KNN · SVM

특성 범위가 크게 다르면 큰 숫자의 특성이 거리·경계 계산을 지배한다. 손글씨 SVM 실습은 MinMaxScaler로 0~1 범위를 사용했다.

from sklearn.preprocessing import MinMaxScaler
scaler = MinMaxScaler()
scaler.fit(X_train)
X_train_s = scaler.transform(X_train)
X_test_s = scaler.transform(X_test)
분리 전 전체 데이터에 scaler를 fit하면 test 정보가 섞이는 데이터 누수.

실전 코드 전체 흐름

복붙
import pandas as pd
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.tree import DecisionTreeClassifier

data = pd.read_csv('data.csv')
X = pd.get_dummies(data.drop('target', axis=1))
y = data['target']

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=7
)
model = DecisionTreeClassifier(max_depth=5)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

print('train:', model.score(X_train, y_train))
print('test :', model.score(X_test, y_test))
print('CV   :', cross_val_score(model, X_train, y_train, cv=5).mean())

뜻 + 예시 + 판단법
이 섹션의 목적: 이름이 비슷하거나 방향을 반대로 외우기 쉬운 내용을 실제 문제 예시로 구분하는 곳입니다. 단어만 외우지 말고 “무엇을 예측하는가?”와 “이 값이 점수인가 오차인가?”를 먼저 보세요.

1. 분류와 회귀를 어떻게 구분하나?

분류

결과가 종류·이름·범주 중 하나이다.

예: 합격/불합격, 뇌졸중 O/X, BMI 등급, 손글씨 0~9

판단 질문: 답이 몇 가지 종류 중 하나인가?

회귀

결과가 끊기지 않는 연속적인 숫자이다.

예: 주택가격 3억 2천만 원, 성적 87.5점, 내일 기온 23.4도

판단 질문: 정확한 수치 자체를 예측하는가?

시험 예시: “집이 비싼 집/싼 집인지 예측”은 분류, “집값이 정확히 얼마인지 예측”은 회귀입니다. 같은 소재라도 정답 형태에 따라 달라집니다.

2. LogisticRegression은 왜 회귀가 아니라 분류인가?

이름에는 Regression이 있지만, 선형식의 결과를 sigmoid 함수에 넣어 0~1 사이의 확률로 바꾼 뒤 클래스를 선택합니다.

예측 확률 0.82 → 기준 0.5 이상 → 합격(1)으로 분류
예측 확률 0.23 → 기준 0.5 미만 → 불합격(0)으로 분류

정답 문장: LogisticRegression은 sigmoid 함수를 이용해 클래스의 확률을 계산하는 분류 모델이다.

3. 어떤 평가지표가 클수록 좋고, 어떤 것이 작을수록 좋은가?

지표무엇을 나타내나?좋은 방향이유
정확도전체 중 맞힌 비율클수록 좋음많이 맞힐수록 좋은 모델
R²회귀 모델의 설명력1에 가까울수록 좋음실제 데이터 변화를 잘 설명
MSE오차 제곱의 평균작을수록 좋음예측과 실제의 차이가 작아야 함
RMSEMSE의 제곱근작을수록 좋음이것도 오차이므로 0이 가장 좋음
외우는 법: 정확도·R²는 성적표라 높을수록 좋고, MSE·RMSE는 틀린 정도라 낮을수록 좋습니다.

4. 과대적합과 과소적합은 점수로 어떻게 찾나?

훈련 점수평가 점수판단이유
0.990.70과대적합공부한 문제는 외웠지만 새 문제를 못 풂
0.620.60과소적합훈련 데이터의 규칙조차 충분히 못 배움
0.910.89일반화 양호훈련과 새로운 데이터 모두 잘 맞힘

핵심: 점수 하나만 보지 말고 반드시 train과 test의 차이를 함께 봅니다.

5. 원-핫 인코딩은 왜 필요한가?

모델의 입력 X에 “남자”, “여자”, “사무직” 같은 문자열이 있으면 계산할 수 없으므로 숫자로 바꿉니다. 단순히 사무직=1, 서비스직=2로 바꾸면 2가 1보다 크다는 가짜 순서가 생깁니다.

성별=남자 → [남자 1, 여자 0]
성별=여자 → [남자 0, 여자 1]

정답 문장: 순서가 없는 범주형 입력은 범주 수만큼 열을 만드는 원-핫 인코딩으로 숫자화한다.

6. Lasso(L1)와 Ridge(L2)는 무엇이 다른가?

Lasso / L1

중요하지 않은 특성의 가중치를 정확히 0으로 만들 수 있습니다.

→ 필요 없는 특성을 제거하는 특성 선택 효과

Ridge / L2

모든 특성의 가중치를 0에 가깝게 골고루 줄입니다.

→ 특성은 유지하면서 모델을 안정화

공통점: 둘 다 가중치를 제한해 과대적합을 줄입니다. alpha가 너무 크면 모델이 지나치게 단순해져 과소적합될 수 있습니다.

7. scaler는 왜 train에만 fit하나?

올바른 순서: split → scaler.fit(X_train) → transform(X_train) → transform(X_test)

test는 처음 보는 데이터 역할입니다. test까지 이용해 최솟값·최댓값을 미리 학습하면 시험 답을 살짝 본 것과 같은 데이터 누수가 됩니다.

8. fit / predict / score에는 무엇을 넣나?

함수넣는 데이터뜻
fitX_train, y_train문제와 정답을 함께 보고 규칙 학습
predictX_test평가 문제만 보고 정답 예측
scoreX_test, y_test예측과 실제 정답을 비교해 점수 계산
자주 하는 실수: predict(X_test, y_test)는 틀립니다. 예측할 때는 실제 정답을 모델에 알려주면 안 되므로 X_test만 넣습니다.
