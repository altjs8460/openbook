4. JOIN

Oracle / ANSI / OUTER / SELF
JOIN: 공통 컬럼을 기준으로 서로 다른 테이블을 가로로 연결.

Oracle JOIN

SELECT E.EMPLOYEE_ID, E.LAST_NAME, D.DEPARTMENT_NAME
FROM EMPLOYEES E, DEPARTMENTS D
WHERE E.DEPARTMENT_ID = D.DEPARTMENT_ID;

ANSI JOIN

SELECT E.LAST_NAME, D.DEPARTMENT_NAME
FROM EMPLOYEES E
JOIN DEPARTMENTS D
ON E.DEPARTMENT_ID = D.DEPARTMENT_ID;
종류핵심
LEFT OUTER왼쪽 전부, Oracle에서는 오른쪽에 (+)
RIGHT OUTER오른쪽 전부, Oracle에서는 왼쪽에 (+)
FULL OUTER양쪽 전부, ANSI 문법
SELF JOIN같은 테이블을 자기 자신과 JOIN
SELECT E.LAST_NAME AS 직원, M.LAST_NAME AS 매니저
FROM EMPLOYEES E, EMPLOYEES M
WHERE E.MANAGER_ID = M.EMPLOYEE_ID;

9. 서브쿼리

단일행 / 다중행 / DUAL
서브쿼리: SELECT문 안에 또 다른 SELECT문이 괄호로 들어있는 것. 괄호 안쪽 SELECT가 먼저 실행되고 바깥 SELECT가 그 결과를 사용.

수업 실습 테이블

CREATE TABLE 반_성적표(
 학생ID NUMBER(6) PRIMARY KEY,
 이름 VARCHAR2(20) NOT NULL,
 반 VARCHAR2(10),
 점수 NUMBER(6)
);

INSERT ALL + DUAL

INSERT ALL
 INTO 반_성적표 VALUES (1,'유진','1반',NULL)
 INTO 반_성적표 VALUES (2,'찬희','1반',95)
 INTO 반_성적표 VALUES (3,'윤현','1반',72)
 INTO 반_성적표 VALUES (4,'영표','2반',90)
 INTO 반_성적표 VALUES (5,'예순','2반',66)
 INTO 반_성적표 VALUES (6,'해도','2반',90)
 INTO 반_성적표 VALUES (7,'예순','3반',78)
 INTO 반_성적표 VALUES (8,'승환','3반',88)
 INTO 반_성적표 VALUES (9,'나영','3반',84)
 INTO 반_성적표 VALUES (10,'민성','3반',60)
SELECT * FROM DUAL;
DUAL: INSERT ALL 문법 끝에 서브쿼리가 필요해서 형식을 맞추기 위해 Oracle 기본 가짜 테이블 DUAL을 사용.

찬희보다 점수가 낮은 학생

SELECT 이름, 점수
FROM 반_성적표
WHERE 점수 < (
 SELECT 점수
 FROM 반_성적표
 WHERE 이름 = '찬희'
);
읽는 순서: 안쪽에서 찬희 점수 95를 먼저 조회 → 바깥에서 95보다 낮은 학생 조회.
구분괄호 안 결과수업 기준
단일행 서브쿼리1개=, >, <, >=, <= 같은 비교 연산자
다중행 서브쿼리여러 개IN
SELECT 이름, 반, 점수
FROM 반_성적표
WHERE 반 IN (
 SELECT 반
 FROM 반_성적표
 WHERE 점수 >= 90
);
서브쿼리 결과가 여러 개인데 = 같은 단일 비교 연산자를 쓰지 않도록 먼저 결과 개수 확인.
