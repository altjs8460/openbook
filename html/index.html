2. 강조 태그

b 시각적 굵게 · strong 의미 강조 · mark 배경 강조 · sup 위첨자 · sub 아래첨자

<strong>중요 내용</strong>
<mark>강조</mark>
2<sup>2</sup>
H<sub>2</sub>O

3. 리스트

ul, ol 안에는 li가 필요.

<ul type="square">
  <li>html</li>
  <li>css</li>
</ul>

<ol type="i">
  <li>등원하기</li>
  <li>수업듣기</li>
</ol>

4. 이미지

필수 속성: src

<img src="이미지주소" width="300px">
<img src="../img/고먐미.jpg" width="300px">

./ 현재 위치 · ../ 상위 폴더 · / 최상위

5. a 태그

필수 속성: href

<a href="https://www.naver.com">네이버로 이동</a>

이미지에 링크를 걸려면 a 안에 img를 넣기.

6. 테이블

태그/속성역할
table표 선언
caption표 제목
tr행
th제목 셀
td데이터 셀
colspan좌우 병합
rowspan위아래 병합
<table border="1">
 <tr><th colspan="2">메뉴</th></tr>
 <tr><td>아메리카노</td><td rowspan="2">3500</td></tr>
 <tr><td>카페라떼</td></tr>
</table>
병합 후 겹치는 td/th는 제거하거나 주석 처리.

7. Form

method=get: URL에 내용이 보일 수 있음 · post: URL 노출 없이 전송 · action: 전송 위치

<form method="get" action="#">
 ID <input type="text" name="id" placeholder="아이디 입력">
 PW <input type="password" name="pw" maxlength="10">
 <input type="submit" value="전송하기">
 <input type="reset">
</form>

선택

축구 <input type="checkbox" name="hobby" value="soccer">
남 <input type="radio" name="gender" value="man">
여 <input type="radio" name="gender" value="woman">
radio는 같은 질문끼리 name을 같게 해야 하나만 선택됨.

select / textarea

<select>
 <option>A형</option>
 <option>B형</option>
</select>
<textarea cols="30" rows="5"></textarea>
