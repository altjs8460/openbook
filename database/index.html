1. 🗃️ DB 개념 + 모델링

공유·통합·저장·운영
DB: 여러 사용자가 공유하여 사용할 수 있도록 통합해서 저장한 운영 데이터의 집합.

파일 시스템 방식은 실시간 공유 불가, 동기화 문제, 누락·중복 가능성이 있고 DBMS는 통합·일관 관리와 공동 사용에 유리.

요구사항 분석 → 개념적 모델링 → 논리적 모델링 → 물리적 모델링 → 데이터베이스

3. 🔢 SQL 실행 순서

FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
1 FROM
2 WHERE
3 GROUP BY
4 HAVING
5 SELECT
6 ORDER BY
함정: WHERE가 SELECT보다 먼저 실행되므로 WHERE절에서 SELECT 별칭 사용 불가.

4. 🔎 SELECT / DISTINCT / 별칭

* / DISTINCT / AS
SELECT *
  FROM EMPLOYEES;
SELECT EMPLOYEE_ID, FIRST_NAME, HIRE_DATE
  FROM EMPLOYEES;
SELECT DISTINCT DEPARTMENT_ID
  FROM EMPLOYEES;
SELECT SALARY AS "급여",
       SALARY*12 AS "연봉"
  FROM EMPLOYEES;
컬럼명이 헷갈리면 먼저 SELECT * 로 전체 구조 확인.

5. ⭕ NULL 기본

0/공백과 다름
NULL은 아직 정의되지 않은 값. 0이나 공백과 다름. NULL과 산술 연산 → NULL, 일반 비교 → FALSE.

6. 🎯 WHERE + 비교/등가

= > >= < <= != <>
SELECT *
  FROM EMPLOYEES
 WHERE JOB_ID = 'IT_PROG';
SELECT FIRST_NAME, SALARY
  FROM EMPLOYEES
 WHERE SALARY <= 5000;
SELECT FIRST_NAME, JOB_ID
  FROM EMPLOYEES
 WHERE JOB_ID <> 'FI_ACCOUNT';
SQL 비교는 등호 하나(=). 같지 않다는 !=, <>, ^=, NOT = 사용 가능하며 수업 노트에서는 <>를 많이 사용.

7. 🧠 AND / OR

AND 우선
SELECT EMPLOYEE_ID, FIRST_NAME
  FROM EMPLOYEES
 WHERE DEPARTMENT_ID = 90
   AND SALARY >= 5000;
SELECT FIRST_NAME, EMPLOYEE_ID, SALARY*12 AS ANNSAL
  FROM EMPLOYEES
 WHERE (DEPARTMENT_ID = 100 OR DEPARTMENT_ID = 50)
   AND SALARY*12 >= 10000;
AND가 OR보다 우선. OR을 먼저 처리하려면 소괄호.

8. 🕳️ IS NULL / IS NOT NULL

NULL 전용 비교
SELECT FIRST_NAME, PHONE_NUMBER
  FROM EMPLOYEES
 WHERE PHONE_NUMBER IS NULL;
SELECT FIRST_NAME, PHONE_NUMBER
  FROM EMPLOYEES
 WHERE PHONE_NUMBER IS NOT NULL;
= NULL / != NULL / <> NULL 사용 금지.

9. 📚 IN / NOT IN

여러 값
SELECT *
  FROM EMPLOYEES
 WHERE DEPARTMENT_ID IN (30,50,90);
SELECT FIRST_NAME, MANAGER_ID
  FROM EMPLOYEES
 WHERE MANAGER_ID NOT IN (145,146,147,148,149);
NOT IN 괄호 안에 NULL이 들어가면 결과가 나오지 않을 수 있음.

10. 📏 BETWEEN

범위
SELECT FIRST_NAME, SALARY
  FROM EMPLOYEES
 WHERE SALARY BETWEEN 10000 AND 19999;

11. 🔤 LIKE + 와일드카드

% / _
패턴뜻
'S%'S로 시작
'%s's로 끝
'%s%'s 포함
'1__'1로 시작하는 3글자
SELECT FIRST_NAME
  FROM EMPLOYEES
 WHERE LOWER(FIRST_NAME) LIKE '%s%';

12. 🔡 문자 함수

UPPER / LOWER / LENGTH / SUBSTR / REPLACE / CONCAT / TRIM
함수역할
UPPER/LOWER대문자/소문자
LENGTH문자열 길이
SUBSTR문자열 추출
REPLACE문자 대체/제거
CONCAT문자열 합치기
TRIM문자 제거
SELECT HIRE_DATE,
       SUBSTR(HIRE_DATE,1,2) AS 연도,
       SUBSTR(HIRE_DATE,4,2) AS 월,
       SUBSTR(HIRE_DATE,7) AS 일
  FROM EMPLOYEES;
SELECT '입사일은 ' || HIRE_DATE || '입니다.'
  FROM EMPLOYEES;

13. 🔢 숫자 함수

MOD / ROUND / TRUNC / DUAL
SELECT MOD(15,6), MOD(14,2)
  FROM DUAL;
SELECT ROUND(15.65), TRUNC(15.65),
       ROUND(15.65,1), TRUNC(15.65,1)
  FROM DUAL;
DUAL: 임시 연산/함수 결과 확인용 더미 테이블.

14. 📅 날짜 함수

SYSDATE / ADD_MONTHS
SELECT SYSDATE,
       SYSDATE+1,
       SYSDATE+1/24,
       SYSDATE+1/24/60
  FROM DUAL;
SELECT ADD_MONTHS(SYSDATE,1),
       ADD_MONTHS(SYSDATE,-1)
  FROM DUAL;

15. 🔁 형변환

TO_CHAR / TO_NUMBER / TO_DATE
SELECT TO_CHAR(SYSDATE,'YY/MM/DD/DAY') FROM DUAL;
SELECT TO_NUMBER('1')+1 FROM DUAL;
SELECT TO_DATE('20230504','YYYY/MM/DD') FROM DUAL;
수업 필기 우선순위: 날짜형 > 숫자형 > 문자형.

16. 🧯 NVL / NVL2

NULL 대체
SELECT COMMISSION_PCT,
       NVL(COMMISSION_PCT,0)
  FROM EMPLOYEES;
SELECT MANAGER_ID,
       NVL2(MANAGER_ID,'직원','관리자')
  FROM EMPLOYEES;

17. 🔀 DECODE

분기 함수
SELECT FIRST_NAME, DEPARTMENT_ID, SALARY,
       DECODE(DEPARTMENT_ID,
              100,SALARY*2,
              90,SALARY*1.9,
              80,SALARY*1.8,
              SALARY) AS 성과급
  FROM EMPLOYEES;

18. 📊 그룹 함수

SUM / COUNT / MAX / MIN / AVG
SELECT SUM(SALARY) AS 급여총합,
       COUNT(SALARY) AS 급여개수,
       MAX(SALARY) AS 최대급여,
       MIN(SALARY) AS 최소급여,
       ROUND(AVG(SALARY)) AS 급여평균
  FROM EMPLOYEES;
