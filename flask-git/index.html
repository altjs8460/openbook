1. 🧩 Flask 기본 구조

Flask / route / run
서버 제작 순서: 설계도면 호출 → 서버 역할 정의 → 서버 실행
from flask import Flask

app = Flask(__name__)

@app.route('/')
def hello():
    return 'hello world'

if __name__ == '__main__':
    app.run(host='localhost', port=5000)
코드뜻
Flask(__name__)Flask 서버 생성
@app.route('/')요청 경로 설정
return클라이언트에게 응답
app.run()서버 실행

5. 📬 GET vs POST

method
구분GETPOST
전송URL에 데이터 포함URL에 직접 노출되지 않음
대표 사용검색/조회로그인/회원가입 등
Flask 값 받기request.args.get()request.form.get()
시험 핵심: HTML method와 Flask methods가 일치해야 함.

6. 📥 GET 데이터 처리

request.args.get
@app.route('/getlogin', methods=['get'])
def getlogin():
    user_id = request.args.get('id')
    user_pw = request.args.get('pw')

    if user_id == 'qweqwe' and user_pw == '1234':
        return render_template('index.html')
    else:
        return render_template('login.html')

7. 📤 POST 데이터 처리

request.form.get
@app.route('/postlogin', methods=['POST'])
def postlogin():
    user_id = request.form.get('id')
    user_pw = request.form.get('pw')

    if user_id == 'qweqwe' and user_pw == '1234':
        return render_template('index.html')
    else:
        return render_template('login.html')
