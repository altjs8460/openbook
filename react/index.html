헷갈리기 쉬운 짝

차이를 한 문장으로 설명해 보세요.

Props ↔ State

Props는 부모가 건넨 값. State는 컴포넌트가 관리하는 변하는 값.

map ↔ filter

map은 각 항목을 바꿔 새 배열 생성. filter는 조건을 통과한 항목만 남김.

Effect ↔ 이벤트

Effect는 렌더 뒤 의존성이 바뀔 때. 핸들러는 클릭·입력 같은 사용자 동작 때.

Context ↔ Zustand

Context는 Provider로 감싸고 useContext로 접근. Zustand는 store hook으로 상태를 가져옴.

React와 JSX

React01 · 첫 수업 PPT: 개요와 JSX

01 · BASICS

React는 무엇인가요?

사용자 인터페이스를 만들기 위한 JavaScript 라이브러리예요. 화면을 작은 컴포넌트로 나누고 데이터가 바뀌면 필요한 화면을 다시 그려요.

라이브러리와 프레임워크 라이브러리는 필요한 기능을 골라 쓰는 도구에 가깝고, 프레임워크는 전체 구조와 실행 흐름을 더 많이 정해 둔 틀이에요.

JSX의 기본 규칙

  • JS 값이나 표현식은 { } 안에 작성해요.
  • 여러 요소를 반환할 때 하나의 부모로 감싸요. 빈 Fragment <> </>는 실제 DOM 요소를 추가하지 않아요.
  • JSX 안에서는 if문 대신 삼항 연산자나 조건 && 요소를 써요.
  • HTML의 class 대신 className. 태그는 소문자, 컴포넌트는 대문자로 시작해요.
  • img처럼 닫는 태그가 없는 요소도 <img />처럼 닫아요.
JSX에서 변수와 조건 사용
function App() {
  const name = '미선';
  const age = 20;
  return (
    <>
      <h1>안녕하세요, {name}</h1>
      <p>{age >= 19 ? '성인' : '미성년자'}</p>
    </>
  );
}

인라인 스타일

스타일은 객체로 넘기고 CSS 속성 이름은 camelCase로 써요.

스타일 객체
const boxStyle = {
  backgroundColor: 'pink',
  fontSize: '24px',
};
<h1 style={boxStyle}>반가워요</h1>
<p style={{ color: 'navy' }}>안녕</p>

조건부 출력

삼항 연산자와 &&
{isLogin ? <p>환영합니다</p> : <p>로그인해 주세요</p>}
{hasNotice && <span>새 알림</span>}

삼항은 둘 중 하나를 고르고, &&는 조건이 참일 때 오른쪽 UI를 보여줘요.

컴포넌트와 Props

React02 · 반복 UI를 나누고 값 전달하기

02 · COMPONENTS

컴포넌트 만들기

화면의 한 부분을 재사용 가능한 단위로 만든 것이 컴포넌트예요. 함수형 컴포넌트는 대문자로 시작하고 JSX를 반환합니다.

자식 컴포넌트 정의와 사용
function Member({ team, name }) {
  return <section><p>{team}</p><p>{name}</p></section>;
}
export default Member;

import Member from './Member.jsx';
<Member team="교육운영부" name="미선" />

Props란?

부모 컴포넌트가 자식에게 전달하는 데이터예요. 자식은 함수 인자로 객체 형태의 props를 받아요.

  • 문자열: name="미선"
  • 숫자/불리언/변수: age={32}, isOpen={true}
  • 자식이 props를 직접 수정하지 않아요.

구조 분해 할당

props 객체에서 필요한 속성을 바로 꺼내 써요. 속성명과 변수명이 같아야 합니다.

같은 의미
const Member = (props) => <p>{props.name}</p>;
// 구조 분해
const Member = ({ name }) => <p>{name}</p>;

조건에 따라 가격 표시

상품 컴포넌트
function Goods({ goods, money }) {
  return (
    <div style={{ backgroundColor: money > 10000 ? 'salmon' : 'white' }}>
      <p>상품: {goods}</p><p>가격: {money}원</p>
      {money > 10000 && <p>가격이 높아요</p>}
    </div>
  );
}

부모는 goods와 money를 전달하고, 자식은 그 값으로 내용과 스타일을 결정해요.

자료형 주의 money="4500"은 문자열입니다. 숫자 계산을 하려면 money={4500}처럼 숫자로 전달하거나 Number로 변환하세요.

State와 이벤트

React03 · 입력·클릭에 반응하는 화면 만들기

03 · INTERACTION

State는 화면이 기억하는 값

일반 변수만 바꾸면 React가 화면을 다시 그릴 이유를 알지 못해요. 화면에 반영해야 하는 값은 State에 저장하고 setter로 갱신합니다.

숫자 카운터
import { useState } from 'react';
function Counter() {
  const [num, setNum] = useState(0);
  return (
    <><p>{num}</p>
      <button onClick={() => setNum(num - 1)}>-1</button>
      <button onClick={() => setNum(num + 1)}>+1</button>
    </>
  );
}

useState는 현재 상태와 갱신 함수를 제공해요. setter 호출은 상태 변경을 요청하고 화면 재렌더링을 일으킵니다.

이벤트 연결

  • React 이벤트는 camelCase: onClick, onChange.
  • 클릭 때 실행하려면 함수 참조: onClick={handleClick}.
  • onClick={handleClick()}은 렌더 때 즉시 실행해요.
  • 인자를 넘길 때는 onClick={() => remove(id)}.

이벤트 객체로 값 읽기

버튼 글자는 e.target.innerText, 입력값은 e.target.value예요.

입력과 선택값
const handleClick = (e) => {
  const selected = Number(e.target.innerText);
  setMyNum(selected);
};
const handleChange = (e) => setText(e.target.value);
<input onChange={handleChange} />

입력폼과 출력

입력값 저장 후 버튼으로 출력
function Echo() {
  const [input, setInput] = useState('');
  const [result, setResult] = useState('');
  return (
    <>
      <input value={input} onChange={e => setInput(e.target.value)} />
      <button onClick={() => setResult(input)}>입력</button>
      <p>{result}</p>
    </>
  );
}

value와 onChange를 함께 쓰면 State가 입력값을 관리하는 제어 컴포넌트가 됩니다.

수업 코드에서 발견한 오타 e.target.innetText는 오타예요. innerText가 맞습니다. setter 직후 같은 실행에서 State를 읽으면 이전 렌더의 값이 보일 수 있어요.

배열과 목록 렌더링

React01 · 반복문 / React04 · map, filter, 데이터 목록

04 · LISTS

map으로 배열을 UI로 바꾸기

map은 각 배열 항목에 함수를 적용해 새 배열을 반환해요. 각 JSX 항목에 안정적인 key를 주면 React가 추가·삭제·순서 변경을 추적할 수 있어요.

문자 배열 → 리스트
const names = ['아이유', 'BTS', '손흥민'];
return <ul>
  {names.map(name => <li key={name}>{name}</li>)}
</ul>;

콜백은 (요소, 인덱스, 원본 배열)을 받을 수 있어요. 보통 요소와 필요한 경우 인덱스를 사용합니다.

객체 배열 출력

속성 표시
const people = [
  { id: 10, name: '아이유', age: 30 },
  { id: 11, name: '손흥민', age: 32 },
];
{people.map(person => (
  <p key={person.id}>{person.name} · {person.age}</p>
))}

filter로 조건에 맞는 값만

필터 후 목록 생성
const fruits = ['apple', 'orange', 'banana'];
{fruits.filter(x => x.length > 5)
  .map(x => <p key={x}>{x}</p>)}

변동 가능한 목록은 인덱스보다 데이터의 고유 id를 key로 쓰는 것이 안전해요.

표로 렌더링 map 콜백에서 <tr key={item.id}>를 반환하고 속성은 <td>에 표시해요. 배열은 무엇을 반복할지, JSX는 어떻게 보일지를 정합니다.

05 · SHARED STATE

자식 입력을 부모가 쓰려면: 상태 끌어올리기

데이터는 보통 부모에서 자식으로 내려가요. 자식에서 바꾼 값을 부모가 사용해야 한다면 상태를 공통 부모에 두고 변경 함수를 props로 전달합니다.

값과 콜백 전달
function Parent() {
  const [text, setText] = useState('');
  return (
    <>
      <Child value={text} onChange={e => setText(e.target.value)} />
      <p>자식 입력: {text}</p>
    </>
  );
}
function Child({ value, onChange }) {
  return <input value={value} onChange={onChange} />;
}

수업의 Ex01_Main 예제처럼 값은 부모→자식, 콜백 실행 결과는 자식→부모로 전달됩니다.

Context API

  1. createContext로 Context 생성
  2. Provider에서 State 생성, value로 제공
  3. 쓸 컴포넌트를 Provider로 감싸기
  4. 자손에서 useContext로 값 사용
기본 모양
const ColorContext = createContext(null);
function ColorProvider({ children }) {
  const [color, setColor] = useState('red');
  return (
    <ColorContext.Provider value={{ color, setColor }}>
      {children}
    </ColorContext.Provider>
  );
}
const { color, setColor } = useContext(ColorContext);

Zustand

수업에서 다룬 별도 store 방식이에요. 상태 변경 액션을 store에 정의하고 필요한 컴포넌트에서 hook으로 가져옵니다.

store와 읽기
const useColorStore = create(set => ({
  color: 'red',
  changeColor: value => set({ color: value }),
}));
const color = useColorStore(state => state.color);
자료형 주의 불리언은 따옴표 없는 true/false예요. useState('true')는 문자열이므로 useState(true)로 초기화해야 합니다.

06 · SIDE EFFECTS

useEffect와 의존성 배열

렌더링 자체가 아닌 외부 작업을 수행하는 Hook이에요. API 요청, 타이머, 브라우저 이벤트 연결 등에 씁니다.

형태실행 시점예시
useEffect(fn)매 렌더 후렌더마다 필요한 외부 동기화
useEffect(fn, [])마운트 후최초 데이터 요청
useEffect(fn, [num])처음과 num 변경 후num과 동기화
Effect가 cleanup 함수를 반환하면 다시 실행되기 전이나 컴포넌트가 제거될 때 정리 작업을 할 수 있어요. 개발 StrictMode에서는 초기 Effect가 추가로 실행되는 것처럼 보일 수 있습니다.

클래스 생명주기와 함수형 대응

클래스 메서드뜻함수형에서 자주 쓰는 방식
constructor초기 설정함수 본문과 useState 초기값
renderUI 반환컴포넌트의 return
componentDidMount처음 화면에 붙은 뒤useEffect(fn, [])
componentDidUpdate값 갱신 뒤useEffect(fn, [값])
componentWillUnmount제거 직전 정리Effect의 cleanup

fetch + async/await

처음 화면이 나온 후 요청하고, 응답을 JSON으로 바꾸어 State에 저장한 뒤 목록을 그려요.

API 목록
const [items, setItems] = useState([]);
useEffect(() => {
  async function load() {
    const response = await fetch('/api/items');
    const data = await response.json();
    setItems(data.items);
  }
  load();
}, []);
return items.map(x => <p key={x.id}>{x.name}</p>);

fetch와 response.json 모두 비동기 작업이라 await로 기다립니다.

useRef로 DOM 접근

렌더를 일으키지 않는 참조값을 저장하거나 input에 포커스 주기처럼 DOM 접근이 필요할 때 사용해요.

입력 비우고 포커스
const inputRef = useRef(null);
function handleClick() {
  inputRef.current.value = '';
  inputRef.current.focus();
}
<input ref={inputRef} />

ref.current를 바꿔도 재렌더링은 일어나지 않아요.

수업 게임: 난수 비교

사용자 선택과 컴퓨터 선택을 각 State에 저장해요. 결과는 둘에서 바로 계산할 수 있습니다.

1~3 숫자 비교
const [mine, setMine] = useState(null);
const [computer, setComputer] = useState(null);
const result = mine === null ? '게임 시작 전'
  : mine === computer ? '정답!' : '틀렸습니다!';
function play(e) {
  const selected = Number(e.currentTarget.textContent);
  const random = Math.floor(Math.random() * 3) + 1;
  setMine(selected);
  setComputer(random);
}

Math.random은 0 이상 1 미만이므로 floor(random * 3) + 1은 1, 2, 3을 생성해요.

상태 갱신 직후 주의 setter를 불러도 같은 실행 흐름의 mine은 즉시 바뀌지 않아요. 새 입력값을 지역 변수에 두고 비교하거나, 파생 결과를 렌더 중 계산하세요.

라우터 연결

앱 전체를 BrowserRouter로 감싸고 Routes 안에 URL 경로와 화면 컴포넌트를 연결합니다.

main.jsx / App.jsx
// main.jsx
<BrowserRouter><App /></BrowserRouter>

// App.jsx
<Routes>
  <Route path="/" element={<Main />} />
  <Route path="/about/:num" element={<About />} />
</Routes>

Link로 이동

페이지 전체를 다시 불러오지 않고 경로를 바꾸는 링크예요.

선언형 이동
<Link to="/about/3">소개 페이지</Link>

useNavigate로 이동

버튼이나 조건에 따라 코드에서 이동할 때 사용해요.

함수 호출로 이동
const navigate = useNavigate();
const handleClick = () => navigate('/about/3');

URL 파라미터 읽기

경로의 :num 자리에 들어온 값은 useParams가 객체로 돌려줍니다.

About.jsx
const { num } = useParams();
return <p>About {num}</p>;
수업의 /about/:num 경로에 맞춰 이동할 때는 /about/3처럼 파라미터를 포함하세요. /about만 이동하면 이 Route와 일치하지 않아요.

1. 입력 문장을 버튼 클릭 후 출력

function TextEcho() {
  const [text, setText] = useState('');
  const [result, setResult] = useState('');
  return (
    <>
      <input value={text} onChange={e => setText(e.target.value)} />
      <button onClick={() => setResult(text)}>출력</button>
      <p>{result}</p>
    </>
  );
}

2. 1부터 100까지 짝수 출력

짝수는 2로 나눈 나머지가 0인 수예요. 배열을 만든 뒤 map으로 출력하면 JSX가 간결합니다.

풀이
const evens = [];
for (let n = 1; n <= 100; n++) {
  if (n % 2 === 0) evens.push(n);
}
return evens.map(n => <p key={n}>{n}</p>);

객관식

JSX에서 변수 name을 출력하는 문법은?

정답 ②. JSX의 JavaScript 표현식은 중괄호 안에 씁니다. ${...}는 템플릿 문자열 문법이에요.
객관식

useState(0)가 반환하는 값의 순서는?

정답 ②. const [count, setCount] = useState(0)처럼 현재 상태와 갱신 함수를 받습니다.
서술형

Props와 State의 차이를 설명하세요.

Props는 부모가 자식에게 전달하는 데이터로 자식이 직접 바꾸지 않습니다. State는 컴포넌트가 관리하는 변경 가능한 데이터이며 setter로 갱신하면 화면이 다시 렌더링됩니다.
코드 읽기

items.filter(x => x.price > 1000).map(x => <p key={x.id}>{x.name}</p>)는 무엇을 하나요?

가격이 1,000보다 큰 객체를 filter로 고르고, map으로 문단 JSX를 만들어 보여줍니다. 각 항목은 id를 key로 씁니다.
오류 찾기

<button onClick={save()}>저장</button>의 문제는?

렌더링 때 save가 즉시 실행됩니다. 클릭 시 실행하려면 onClick={save}. 인자를 넘길 때는 onClick={() => save(id)}를 씁니다.
실습형

버튼을 누르면 숫자가 1씩 올라가는 컴포넌트를 작성하세요.

function Counter() {
  const [count, setCount] = useState(0);
  return <><p>{count}</p>
    <button onClick={() => setCount(count + 1)}>+1</button></>;
}
setter가 값을 바꾸고 React가 화면을 다시 그려 새 숫자를 보여줍니다.
