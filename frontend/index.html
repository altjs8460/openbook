CSS 5. 🧭 Flex

display:flex
Flex: 부모가 자식들의 배치를 조정하는 기능.
속성기능
display:flexFlex 시작
flex-direction배치 방향 row / column
justify-content메인축 정렬
align-items교차축 정렬
gap아이템 사이 간격
flex-basis자식의 기본 크기
flex-grow남는 공간 늘어나기 비율
flex-shrink공간 부족 시 줄어드는 비율

  display:flex;
  justify-content:center;
  align-items:center;
  gap:10px;
}

CSS 6. 📍 position

실습 3. 🧯 안 될 때 확인 순서

오류 찾기
증상먼저 확인
CSS가 안 먹음class는 ., id는 #를 썼는지
이미지가 안 나옴src 경로, 파일명, 확장자 확인
링크가 안 감href 값 확인
Flex 정렬 안 됨부모에 display:flex가 있는지
JS 요소가 nullid/class 이름 오타, script 실행 시점 확인
버튼 클릭해도 반응 없음addEventListener 대상 요소를 제대로 찾았는지
10 + 20이 1020prompt/input 값이 문자열인지 확인 후 Number()
while이 안 끝남증감식 또는 break가 있는지
여러 요소 중 하나만 바뀜querySelectorAll + 반복문이 필요한지
태그가 글자로 보임innerText가 아니라 innerHTML이 필요한지
input 값이 안 나옴.value 사용 여부
fetch 문법 오류=>, 괄호, 중괄호, .then() 위치
