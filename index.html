1. 🟢 입출력 + 변수

prompt / console / let

prompt() 입력(문자열), confirm() Boolean, console.log() 콘솔, alert() 알림창.

let name = prompt('이름을 입력하세요');
console.log(`안녕하세요~ ${name}님!`);
키워드재선언재할당
var가능가능
let불가능가능
const불가능불가능

2. 🔵 자료형 + 형변환

typeof / Number / parseInt
핵심: prompt 결과는 문자열. 숫자 계산이면 형변환.
let num1 = parseInt(prompt('첫 번째 숫자'));
let num2 = parseInt(prompt('두 번째 숫자'));
console.log(num1 + num2);

Number() 숫자 · parseInt() 정수 · parseFloat() 실수 · String()/toString() 문자열 · toFixed(n) 소수점 자리

3. 🟠 연산자

% / === / && / ? :

산술 + - * / % · 비교 == === != !== · 논리 ! && || · 삼항 조건 ? 참 : 거짓

let num = parseInt(prompt('숫자 입력'));
console.log(num % 2 === 0 ? '짝수' : '홀수');

4. 🟡 조건문

if / else if / switch
if (조건1) {
    // 참
} else if (조건2) {
    // 조건2 참
} else {
    // 모두 거짓
}
switch (값) {
 case 값1: 실행문; break;
 default: 실행문; break;
}

5. 🔁 반복문

while / for / break
for (let i = 1; i <= 10; i++) {
    console.log(i);
}
무한반복: while 안에서 값이 바뀌는지, while(true)면 break가 있는지 확인.

6. 📦 배열 Array

push / pop / splice / length

array.length · push() · pop() · splice() · includes() · indexOf() · slice()

for (let i = 0; i < array.length; i++) {
    console.log(array[i]);
}

7. 🧩 함수

function / return / =>
function sum(num1, num2) {
    return num1 + num2;
}
console.log(sum(3, 10));
const func = (num1, num2) => {
    console.log(num1 + num2);
};

8. 🗂️ 객체 Object

key:value / obj.key
let person = { name:'김미선', age:20 };
console.log(person.name);

10. 🖱️ Event + CSS

click / keyup / style
let p = document.getElementById('p_event');
p.addEventListener('click', () => {
    console.log('클릭!');
});
box.style.marginLeft = '100px';
box.style.backgroundColor = 'pink';

11. 🌐 fetch 데이터 통신

fetch / then / json / catch
fetch(movieUrl)
 .then((res) => res.json())
 .then((res) => {
     console.log(res);
 })
 .catch((error) => {
     console.log(error);
 });
흐름: 버튼 → click → 날짜 → URL → fetch → res.json() → 배열 → for → HTML → innerHTML → catch
